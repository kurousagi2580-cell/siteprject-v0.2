# 記事Markdownエディターの使い方

記事の新規作成・編集画面にある「本文」タブでは、左側でMarkdownを入力し、右側のプレビューで表示を確認できます。上部のツールボタンを使うか、以下の記法を直接入力してください。

## 文字の装飾

| 機能 | 入力例 | 表示 |
| --- | --- | --- |
| 太字 | `**太字**` | **太字** |
| 斜体 | `*斜体*` | *斜体* |
| 下線 | `++下線++` | <u>下線</u> |
| 文字色 | `{{color:#ff8800|色付き文字}}` | `#ff8800` の文字色 |
| 文字サイズ | `{{size:24px|大きい文字}}` | 24px の文字 |

文字色は `#RGB` または `#RRGGBB` で指定します。文字サイズは `8px` から `72px` の範囲で指定できます。

## 見出し

行の先頭に `#` を付けます。`#` の数で見出しレベルを指定します。

```md
# 見出し1
## 見出し2
### 見出し3
```

エディターの「見出し」メニューから挿入することもできます。見出しは記事ページの目次にも使われます。

## 目次

目次を表示したい場所に、次の記法を単独の行で入力します。記事内に見出しがある場合、その見出しへのリンク一覧を生成します。

```md
[toc]
```

## アンカーリンク

リンク先にしたい場所へ、単独行でアンカーを置きます。IDには英数字、ハイフン、アンダースコア、ピリオド、コロンを使えます。

```md
[anchor=section-id]
```

リンクしたい文字を、アンカーIDを指定した通常のMarkdownリンクで囲みます。

```md
[詳しい説明へ](#section-id)
```

エディターの「アンカー先」ボタンでリンク先を、「アンカーリンク」ボタンでリンクを挿入できます。挿入後、`section-id` を同じIDに揃えてください。見出しには自動でIDが付くため、見出しへのリンクは `[見出しへ](#見出しのID)` としても作成できます。

## 文字揃え

揃えたい範囲を開始タグと終了タグで囲みます。タグはそれぞれ独立した行に置いてください。

```md
[align=right]

右揃えの文章

[/align]
```

`right` の代わりに `left` または `center` を指定できます。エディターの「文字揃え」メニューを使う場合は、揃えたい文章を選択してから揃え方を選んでください。

## 改行と段落

本文欄で通常どおり改行すると、プレビューと記事ページにも改行として反映されます。段落を分ける場合は行の間に空行を入れます。Markdownの仕様上、複数の空行を続けても段落間の空きは増えません。本文と本文の間に余白を追加したい場合は、ツールの「余白を挿入」からサイズを選んでください。

```md
同じ段落の1行目
同じ段落の2行目

これは次の段落です。
```

余白は次の記法でも挿入できます。利用できる高さは16、32、48、64pxです。

```md
本文

[space=32]

ここからプレビューに余白が反映されます。
```

## 画像

画像ボタンを使うか、次の形式で入力します。

```md
![画像の説明](https://example.com/image.png)
```

画像URLには `http` または `https` を使用してください。`代替テキスト` は画像が表示できない場合などに使われる説明です。

## 表

表ボタンでひな形を挿入するか、GitHub Flavored Markdown形式で記述します。

```md
| 項目 | 内容 |
| --- | --- |
| 攻撃力 | 120 |
| 防御力 | 80 |
```

## リンク・引用・リスト

リンクボタン、引用ボタンを使うか、以下の記法を入力します。

```md
[公式サイト](https://example.com)

> 引用文

- リスト項目1
- リスト項目2
```

## 動画・SNSの埋め込み

YouTubeまたはX（Twitter）の投稿URLを、それだけの行に入力すると埋め込み表示になります。

```md
https://youtu.be/動画ID
https://x.com/ユーザー名/status/投稿ID
```

対応URL以外の埋め込みや、HTMLを直接書いて埋め込む方法には対応していません。

## 編集時のポイント

- 「本文」タブでプレビューを確認してから保存してください。
- ツールボタンは、文字を選択してから押すと選択範囲を装飾できます。未選択の場合はサンプル文字が挿入されます。
- 画像やリンクはURLと代替テキスト・リンク文言を置き換えてください。
- HTMLタグは無効化されます。記事本文では上記のMarkdown記法を使用してください。
